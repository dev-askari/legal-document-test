# Legal Document Management Interface

This is a monorepo for a **Legal Document Management Interface** built with React (TypeScript) for the frontend and Node.js (Express) for the backend. The application allows users to upload, view, and manage legal documents (PDFs).

---

## Features

- Upload PDF documents.
- View uploaded documents in a responsive dashboard.
- Display mock extractions from documents.

---

## Prerequisites

Before running the application, ensure you have the following installed:

- **Node.js** (v16 or higher)
- **npm** or **yarn**
- **Git**

---

## Project Structure

The project is divided into two main folders:

### Backend

1. Navigate to the `server` folder:
   ```bash
   cd server
   npm install
   npm start

The backend will run on http://localhost:5000


### Frontend

2. Navigate to the `frontend` folder:
   ```bash
   cd frontend
   npm install
   npm run dev

The frontend will run on http://localhost:5173
